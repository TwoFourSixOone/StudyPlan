## 调整规则
1. SIG-1（知识点薄弱）：在后续计划中增加该知识点的练习量，每天额外安排 1-2 道相关题目
2. SIG-2（掌握度下降）：安排复习任务，将该知识点加入近 3 天的计划中进行巩固
3. SIG-3（学习懈怠）：适当减少每日任务量（减少 20%-30%），降低学习压力
4. SIG-4（进度风险）：加快进度，优先安排未覆盖知识点的学习，同时保证复习不中断
5. 超期错题应优先安排重做，分布在最近 3 天内完成

## newContent 格式要求（严格遵守）

newContent 必须是"题目引用数组"序列化后的 JSON 字符串，每个元素为一道题目的引用：

"[{\"questionId\": 123, \"questionSource\": \"bank\", \"taskType\": \"review\"}]"

- 只能复用上方"未来 7 天已有计划"原内容中出现过的题目引用（questionId + questionSource 组合），禁止编造任何新的题目 ID
- questionSource 取值：bank（题库题）/ generated（生成题）
- taskType 取值：review（复习）/ redo（重做）/ similar（举一反三）/ comprehensive（综合）
- 若该天需要安排未覆盖知识点的新题目（原计划中没有可复用的题目引用），请输出空数组字符串 "[]"，并在 reason 中说明安排意图；系统会将该天标记为"待生成"，由出题 Agent 自动出题
- 引用"未覆盖知识点清单"中的 ID 时，只能出现在 reason 文字说明中，不能写入 newContent

## 输出格式要求

请严格以 JSON 格式输出，包含以下字段：
- modifiedDates: 修改的日期列表，每个元素包含：
  - date: 日期（YYYY-MM-DD 格式，必须在上方未来计划的日期范围内）
  - newContent: 新的计划内容（上述格式的 JSON 字符串）
  - reason: 修改原因
- reason: 总体调整原因说明
- criticalErrorQuestionIds: 需要优先处理的错题 ID 列表

## 注意事项
1. 只输出 JSON 对象，不要包含任何其他文字说明
2. 调整应尽可能紧凑，优先修改最近 7 天内的计划
3. 每天的任务量不应超过 15 道题
4. 如果无需调整，返回空的 modifiedDates 列表并说明原因
