## 调整规则
1. SIG-1（知识点薄弱）：在后续计划中增加该知识点的练习量，每天额外安排 1-2 道相关题目
2. SIG-2（掌握度下降）：安排复习任务，将该知识点加入近 3 天的计划中进行巩固
3. SIG-3（学习懈怠）：适当减少每日任务量（减少 20%-30%），降低学习压力
4. SIG-4（进度风险）：加快进度，每日新增知识点数提升至 cap-day 上限，同时保证复习不中断
5. 超期错题应优先安排重做，分布在最近 3 天内完成

## 输出格式要求

请严格以 JSON 格式输出，包含以下字段：
- modifiedDates: 修改的日期列表，每个元素包含：
  - date: 日期（YYYY-MM-DD 格式）
  - newContent: 新的计划内容（JSON 字符串，包含该天的知识点和题目安排）
  - reason: 修改原因
- reason: 总体调整原因说明
- criticalErrorQuestionIds: 需要优先处理的错题 ID 列表

## 注意事项
1. 只输出 JSON 对象，不要包含任何其他文字说明
2. 调整应尽可能紧凑，优先修改最近 7 天内的计划
3. 每天的任务量不应超过 15 道题
4. 如果无需调整，返回空的 modifiedDates 列表并说明原因
