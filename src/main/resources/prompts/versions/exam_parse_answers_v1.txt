- 学科：{subject}
- 学生年级：{grade}
- 图片总数：{imageTotal} 张（按发送顺序）
- 重试提示：{retryHint}

{questionDigest}

【作答归属（必须遵守）】
1. **红笔（或明显批改色）是老师批改**：题号左侧/页边的红笔字母、正确答案、红笔解题过程、选项上的红 √/×，都不是学生作答。
2. **学生的笔迹**：黑笔、蓝笔，以及**铅笔/灰色笔**（考试中勾选、填空常用铅笔）。
   - 选择题在选项上打勾/圈选/划线 → 输出对应选项标签（例：勾 C → "C"；多选输出全部标签如 "ABD"）；
   - 填空题/解答题写在横线、括号、空白处的答案/过程 → 原样转成纯文本；
   - 铅笔痕迹淡、与印刷内容难区分时：只采信位于作答位置（选项上/横线上/括号内/解答空白处）且与同卷其他作答笔迹一致的痕迹，其余忽略。
3. 整页只有红笔批改、没有学生笔迹作答 → 该题 `answerStatus="blank"`、`studentAnswer=""`，**禁止用红笔答案填充**。
4. 学生答案被老师划掉/订正时，保留学生原始答案；无法分辨谁写的 → `answerStatus="unreadable"`。
5. **答题卡**：学生可能把答案写在答题卡（另一张图片）上。请在所有图片中找该题作答——答题卡用题号对应（题号可能只写数字如"17."、或方框/填涂格），按题号映射到 paperNo；答题卡与该题在题目页都写了时以答题卡为准。**不要因为题目页没写就判 blank：先去答题卡找**。
6. 看不清/被裁切 → `unreadable`；不要猜、不要编造。

【输出要求】
1. 只输出 JSON，不要 Markdown 代码块或解释文字。
2. 顶层对象只包含两个字段：answers（数组）和 imageWarning（可选）。
3. answers 每项：`paperNo`（整数，必须来自题目清单）、`studentAnswer`（纯文本；blank 时为空字符串）、`answerStatus`（answered/blank/unreadable）、`unclearFields`（可选，最多 6 项）。
4. **题目清单里的每一道题都必须输出一条**（没有作答也要输出 blank），不要遗漏；不要输出清单外的 paperNo。**answers 不能为空数组**——空数组视为本次提取失败。
5. 数学符号写成纯文本：√、≤、≥、×、÷、θ、π、x^2、a_n；禁止 LaTeX 反斜杠命令与花括号上下标。
6. 不要在 JSON 前后添加任何说明。
