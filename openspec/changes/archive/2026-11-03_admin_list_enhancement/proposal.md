# Proposal：管理后端列表查询增强（v2 修复版）

> **Change 名称**：`2026-11-03_admin_list_enhancement`  
> **创建日期**：2026-11-03  
> **状态**：草案 v2（修复 BLOCK-1/2/3 + IMP-1~5）

---

## 1. 需求背景

当前系统已完成：
- 后端基础设施（JWT 鉴权、统一响应结构、全局异常处理）
- 学生登录与认证
- 数据导入功能（题库、知识点、先修关系、课程标准）
- 学习目标管理
- 掌握度状态管理（公式引擎、状态更新、状态查询）
- 每日作业核心流程（Agent 出题 → 生成 → 提交 → 批改 → 掌握度更新）
- 错题管理系统（艾宾浩斯周期调度、掌握度联动暂停/重新入队）
- 举一反三新题生成（完整配额逻辑、Agent 生成、相似度检测）
- 专项评测系统（评测创建、批改、掌握度更新、错题入队、历史查询）
- 试卷上传与异步解析系统（OCR 切题、归因 Agent、手动成绩录入）
- 计划调整系统（触发信号检测、调整 Agent、计划 diff、用户确认）
- 学习记录查询与回溯系统（学习记录列表、详情、追溯链）
- 知识点治理功能（知识点列表、启停用、校对标记、超期提醒）

下一步需要实现**管理后端列表查询增强**，提供题目、先修关系、课程标准的列表查看与搜索功能，以及导入日志与错误记录的查询能力。

> **修复 IMP-2 职责澄清**：管理端知识点列表查询归 Change 9（AdminKnowledgePointController）负责，本 Change 不包含知识点列表接口。

根据产品规则 §1.1(4)，管理后端属于 Demo 交付范围，需要提供列表搜索、筛选、分页等通用功能。

---

## 2. 核心目标

1. **题目列表查询**：含搜索、分页、按知识点/难度/题型筛选（修复 IMP-1：列名 `type`）
2. **先修关系列表查询**：含搜索、分页
3. **课程标准列表查询**：含搜索、分页、按学段/学科筛选（修复 IMP-5：`subject` 是 String 字段）
4. **导入日志查询**：含时间范围、数据类型筛选
5. **导入错误记录查询**：含导入批次筛选
6. **分页安全**：限制单页最大 100 条（修复 IMP-4）

## 4. 关键业务约束

| 约束 | 来源 | 说明 |

## 5. 隐性约定检查

| 约定 | 影响 |

| #1 统一响应 | Controller 返回 `Result<T>` |

## 6. 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 列表查询性能 | 中 | 添加复合索引（V9）；避免全表扫描 |
| 大数据量分页 | 中 | 限制单页大小最大 100 条（修复 IMP-4） |
| 搜索条件注入 | 低 | LIKE 查询转义 `%` 和 `_`（修复 IMP-3） |
| 导入日志数据量大 | 低 | 按时间范围筛选；定期归档旧数据 |
