# Proposal：举一反三新题生成与完整配额逻辑

> **Change 名称**：`2026-11-03_similar_question_generation`  
> **创建日期**：2026-11-03  
> **状态**：草案 v6（DETAIL-1~3 修正）

---

## 1. 需求背景

当前系统已完成：
- 后端基础设施（JWT 鉴权、统一响应结构、全局异常处理）
- 学生登录与认证
- 数据导入功能（题库、知识点、先修关系、课程标准）
- 学习目标管理
- 掌握度状态管理（公式引擎、状态更新、查询接口）
- 每日作业核心流程（Agent 出题 → 生成 → 提交 → 批改 → 掌握度更新）
- 错题管理系统（艾宾浩斯周期调度、掌握度联动暂停/重新入队）

当前每日作业生成流程中，举一反三新题部分采用简化逻辑（15 - 错题数 = 新题配额），未实现完整的配额分配策略，且缺少新题质量校验环节。

本次 Change 聚焦于**举一反三新题生成的完整流程**，包括：完整配额逻辑、出题 Agent 调用、检查 Agent 校验、相似度检测、降级处理。

---

## 2. 核心目标

1. **完整配额逻辑**：实现规则 #3 的完整配额分配（原题优先 → 举一反三 → 知识回顾，含极端场景兜底）
2. **出题 Agent 调用**：针对有错题的知识点，调用出题 Agent 生成 2~3 道举一反三新题
3. **检查 Agent 校验**：出题 Agent 生成后，由检查 Agent 校验题目质量（内容合理性、难度匹配、知识点关联）
4. **相似度检测**：本地实现文本相似度检测（SimHash + 余弦相似度），阈值 0.6（字符级粗筛），防止重复题目
5. **循环重试机制**：校验失败或相似度过高时，返回出题 Agent 重新生成，最多循环 5 次
6. **降级处理**：循环 5 次仍失败，记录 `agent_degradation_log`，标记为待人工干预
7. **新题存储**：校验通过的新题写入 `generated_question` 表

## 6. 风险评估

| 风险项 | 风险等级 | 缓解措施 |
|--------|----------|----------|
| 相似度检测准确性 | 中 | 采用 SimHash + 余弦相似度组合，阈值 0.6 为字符级粗筛经验值；语义层由检查 Agent 兜底，登记 TD-SIMILARITY-THRESHOLD |
| 检查 Agent 误判 | 中 | 检查 Agent 负责解题逻辑相似性判断（规则+字符相似度无法覆盖），其余由确定性规则校验，登记 TD-CHECK-AGENT-CAPABILITY |
| Agent 调用超时 | 低 | 30s 超时 + **BLOCK-7 修正**：检查 Agent 超时降级为仅规则校验（项 1-4），规则通过则放行，记录 WARN 日志 |
| 循环 5 次仍失败 | 低 | 记录失败原因到 `agent_degradation_log`，不阻塞其他题目生成 |
| 配额计算复杂度 | 中 | 拆分为独立工具类，P0/P1/P2 优先级体系，单元测试覆盖边界场景（含极端模式、配额极度紧张、KP_MAX 硬上限） |
| 检查 Agent 保守策略 | 低 | 采用“宁可漏放不可误杀”策略，误杀代价高于漏放；登记 TD-CHECK-AGENT-CONSERVATIVE |
| 极端模式错题饥饿风险 | 低 | 长期 >15 道到期错题时某些知识点可能长期顺延，由 Change 10（计划调整系统）处理；登记 TD-EXTREME-MODE-STARVATION |
| `generated_question` 表数据增长 | 低 | 定期归档已作答且超过 30 天的记录（后续 Change 实现） |

## 7. 验收标准

1. **配额计算正确**：完整实现规则 #3 的配额分配逻辑，包括极端场景兜底
2. **新题生成正确**：针对有错题的知识点，生成 2~3 道举一反三新题，难度递进
3. **相似度检测有效**：新题与原题字符级相似度 ≤ 0.6，超过则重试；语义层由检查 Agent 校验解题逻辑差异性
4. **检查 Agent 校验有效**：新题通过内容质量、难度枚举合法性、知识点关联、解题逻辑相似性校验
5. **循环重试正确**：校验失败时返回出题 Agent 重新生成，最多 5 次
6. **降级处理正确**：5 次失败后记录 `agent_degradation_log`，不阻塞流程；检查 Agent 超时时降级为仅规则校验，规则通过则放行
7. **新题存储正确**：校验通过的新题写入 `generated_question` 表
8. **单元测试覆盖**：核心逻辑测试覆盖率 ≥ 80%
