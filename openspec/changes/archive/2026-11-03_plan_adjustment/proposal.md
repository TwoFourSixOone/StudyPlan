## 1. 需求背景

当前系统已完成：
- 后端基础设施（JWT 鉴权、统一响应结构、全局异常处理）
- 学生登录与认证
- 数据导入功能（题库、知识点、先修关系、课程标准）
- 学习目标管理
- 掌握度状态管理（公式引擎、状态更新、查询接口）
- 每日作业核心流程（Agent 出题 → 生成 → 提交 → 批改 → 掌握度更新）
- 错题管理系统（艾宾浩斯周期调度、掌握度联动暂停/重新入队）
- 举一反三新题生成（完整配额逻辑、Agent 生成、相似度检测）
- 专项评测系统（评测创建、批改、掌握度更新、错题入队、历史查询）
- 试卷上传与异步解析系统（OCR 切题、归因 Agent、掌握度更新、错题入队）

下一步需要实现**计划调整系统**，跑通"触发信号检测 → 调整 Agent 生成计划 diff → 用户确认 → 计划更新"的完整学习闭环。

根据产品规则 #5，计划调整由用户点击按钮触发，但调整 Agent 的输出必须基于后端预定义的触发信号，且只输出需要修改日期的计划 diff，不得重新生成整份计划。

---

## 2. 核心目标

1. **触发信号检测**：检测 4 种触发信号（SIG-1~SIG-4），判断是否需要调整计划
2. **调整 Agent 调用**：基于触发信号调用调整 Agent，生成计划 diff
3. **计划 diff 存储**：存储调整 Agent 的输出（仅修改有问题的日期）
4. **用户确认流程**：展示 diff → 用户确认 → 生效
5. **调整历史记录**：记录触发信号、diff 内容、确认时间，可追溯
6. **降级处理**：Agent 失败时返回"请稍后重试"，不生成 diff
7. **错题超 30 天标记**：标记"需重点关注"，由调整 Agent 优先处理

## 4. 关键业务约束

| 约束 | 来源 | 说明 |
|------|------|------|
| 触发信号 SIG-1 | 规则 #5 | 某知识点连续 3 次每日作业正确率 < 60%（窗口 7 天，可配置） |
| 触发信号 SIG-2 | 规则 #5 | 某知识点掌握度单次考试下降 > 0.15（阈值可配置） |
| 触发信号 SIG-3 | 规则 #5 | 连续 2 天每日作业未完成（天数可配置） |
| 触发信号 SIG-4 | 规则 #5 | D_remain × cap_day × eff < \|K_uncovered\|（cap_day/eff 从 application.yml 读取；K_uncovered = 从未学习的知识点） |
| 计划 diff 粒度 | 规则 #5 | 仅修改有问题的日期，不重新生成整份计划 |
| 用户确认 | 规则 #5 | 调整结果需先展示给学生确认，确认后才生效 |
| 降级策略 | 规则 #6 | 调整 Agent 失败返回空 diff，响应"调整暂时失败" |
| 错题超 30 天 | 规则 #3 | 标记"需重点关注"，调整 Agent 优先处理 |
| 调整历史 | 规则 #9 | 记录触发信号列表、diff 内容、用户确认时间，只读不删 |

## 5. 隐性约定检查

| 约定 | 影响 |
|------|------|
| #1 统一响应 | Controller 返回 `Result<T>` |
| #2 异常处理 | Service 抛 `BusinessException`，Controller 不 try-catch |
| #3 分页参数 | 历史列表 `page` 从 1 开始，`size` 默认 10 |

| #9 rollbackFor | 计划更新与历史记录在同一事务内 |
| #10 事务边界 | Agent 调用在事务外，仅数据库写入在事务内 |

| #12 超时降级 | Agent 调用 30s 超时，触发降级 |
| #13 UNIQUE 索引 | plan_adjustment_log 新增唯一索引 |
| #14 Agent 异常分层 | 技术异常与业务异常分层处理 |

## 6. 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 触发信号误判 | 中 | 多信号交叉验证；用户可忽略误判 |
| 调整 Agent 失败 | 中 | 重试 2 次；失败后返回"请稍后重试"；记录降级日志 |
| 计划 diff 冲突 | 低 | 唯一索引 (goal_id, diff_id) + DuplicateKeyException 捕获 |
| 用户未确认导致 diff 堆积 | 低 | 设置 diff 有效期（7 天）；定时任务每天凌晨 2 点批量清理过期 diff |
| 错题超 30 天未处理 | 中 | 调整 Agent 优先处理；标记"需重点关注" |
| 并发调整冲突 | 低 | 同一目标同时只允许一个调整任务 |

## 8. 验收标准

1. 触发信号检测正确（SIG-1~SIG-4）

3. 计划 diff 正确存储（仅修改有问题的日期）

5. 调整历史记录完整（触发信号、diff、确认时间）

8. 无信号命中时返回"暂无需调整"
