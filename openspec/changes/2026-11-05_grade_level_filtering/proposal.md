# Proposal：题目与知识点年级维度过滤

> **Change 名称**：`2026-11-05_grade_level_filtering`
> **创建日期**：2026-11-05
> **版本**：草案 v1

---

## 1. 需求背景

当前系统的题目通过 `knowledgePointId` 关联知识点，知识点关联科目，没有年级维度。学生端 `Student` 实体已有 `grade` 字段，但未被用于题目过滤。

用户反馈：不同年级的学生应看到适合自己年级的题目（如三年级学生只看三年级题目），避免题目难度与年级不匹配。

---

## 2. 核心目标

1. 在知识点（`knowledge_point`）层面增加适用年级范围字段
2. 在题目（`question_bank`）层面增加年级字段（可选，未填时继承知识点年级）
3. 后端出题逻辑按学生年级过滤可用题目
4. 数据导入流程支持年级信息
5. 前端个人中心展示学生年级（已在上一 change 完成）

---

## 3. 功能范围

### 包含

| 模块 | 变更内容 |
|------|---------|
| **数据库** | `knowledge_point` 表新增 `grade_range` 字段；`question_bank` 表新增 `grade` 字段 |
| **后端 Entity** | `KnowledgePoint` 新增 `gradeRange`；`QuestionBank` 新增 `grade` |
| **后端 VO** | `SubjectVO` 新增可用年级列表；`QuestionListVO` 新增年级字段 |
| **后端 Service** | 出题逻辑（`HomeworkServiceImpl`、`AssessmentServiceImpl`）增加年级过滤 |
| **后端 Controller** | 科目列表接口返回该科目覆盖的年级范围 |
| **数据导入** | JSON 导入流程支持 `gradeRange` 和 `grade` 字段解析 |
| **管理后端** | 知识点列表、题目列表展示年级信息；导入 JSON 支持年级字段 |
| **学生端** | 个人中心显示年级（已在 `2026-11-05_student_business_pages` 完成） |

### 不包含

- 学生年级的编辑/设置 UI（当前年级由后端初始化数据或管理端设置）
- 年级维度的统计报表
- 跨年级题目推荐逻辑（当前严格按年级过滤，不做跨年级扩展）
- Prompt 版本更新（Agent 出题时年级过滤由后端 Service 层完成，Agent 不需要感知年级）

## 5. 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 存量题目/知识点无年级数据 | 高 | 新增字段允许 NULL/空值，未标注年级的题目/知识点对所有年级可见（降级策略） |
| 年级过滤导致题目池过小 | 中 | 年级过滤为软过滤——若本年级题目不足，自动扩展至相邻年级 |
| 数据导入 JSON 格式变更 | 中 | 新增字段为可选，旧格式 JSON 仍可正常导入 |
| 后端出题逻辑变更影响面大 | 中 | 年级过滤在题目池筛选阶段完成，不影响出题 Agent 调用链路 |
